A router is a device that forwards packets between different networks. A switch is a device that connects hosts inside a local network using hardware addresses. Protocol is a set of rules that defines how devices exchange data. Bandwidth is the maximum amount of data that a link can carry per second. Latency is the delay that data experiences while travelling between two endpoints. A firewall is a security system that filters traffic using defined rules. Subnetting is a technique that divides a network into smaller logical segments. Gateway is a node that connects two networks using different protocols. Encryption is a process that converts readable data into ciphertext for confidentiality. Ethernet is a wired technology that connects devices in local area networks.

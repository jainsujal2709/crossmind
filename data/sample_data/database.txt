Normalization is a design process that reduces redundancy by organizing tables carefully. A transaction is a unit of work that must complete entirely or not at all. Index is a data structure that speeds up lookups on table columns. A primary key is a column that uniquely identifies every row in a table. A foreign key is a column that references the primary key of another table. Concurrency is the ability of a database to serve many users at the same moment. Atomicity is a property that guarantees a transaction is applied fully or not applied. Query is a request that retrieves or modifies data stored in a database. A schema is a blueprint that describes tables, columns and relationships. Rollback is an operation that undoes changes made by an unfinished transaction.

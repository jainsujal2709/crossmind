Supervised learning is a learning approach that trains models on labeled examples. Classification is a task that predicts discrete categories from input features. Regression is a task that predicts continuous numeric values from input features. Overfitting is a situation where a model performs well on training data but fails on unseen data. Clustering is an unsupervised technique that groups similar data points without labels. Backpropagation is an algorithm that computes gradients to update neural network weights. Gradient descent is an optimization method that minimizes a loss function step by step. Regularization is a technique that penalizes model complexity to reduce overfitting. A neural network is a model made of layered connected neurons that learn representations. Validation is a process that evaluates a model on held out data during training.
